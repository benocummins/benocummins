## 🔨 What I'm building

My [**homelab**](https://github.com/benocummins/homelab) is run like a small production platform, and everything changes through pull requests.

- **Network as code:** UniFi gateway networks imported into Terraform and managed through reviewed plans
- **Containers:** Docker stacks behind Traefik with Let's Encrypt TLS, managed through Dockhand with an outbound-only agent
- **Automation:** Ansible baselines for every host
- **Next:** CI that validates every PR, monitoring and alerting, and k3s

## 🔐 How I work

- **Secrets never touch Git.** Pre-commit secret scanning, push protection, and `.example` files in place of real config
- **Least privilege by default.** Dedicated service accounts and scoped API tokens
- **Segmented networks.** Zone-based firewall policies between VLANs
- **Verified TLS.** Trusted certificates everywhere, with no skipped verification
- **Reviewable changes.** Protected `main`, signed commits, and a plan reviewed before every apply
